# Clanhold — releases

Downloads for **Clanhold**, a pixel-art village-to-city RTS. This repository holds release builds only (no source).

- Website and guide: https://clanhold.pages.dev
- Play in the browser: https://clanhold.clanhold.workers.dev/
- Downloads: see [Releases](https://github.com/blueyetechnology/clanhold-releases/releases/latest) (Mac Apple Silicon, Mac Intel, Windows).

The builds are not code-signed yet, so macOS and Windows warn the first time you open them. The website explains how to open them.
